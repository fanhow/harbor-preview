# Harbor｜Mac 預覽版

Harbor 是 AISR 的 Mac 工具。這一版先解決兩件事：在你的資料夾找回影片，以及把影片和字幕整理成同名檔案。

- [下載 Harbor 0.4.6 預覽版並查看發版說明](https://github.com/fanhow/harbor-preview/releases/tag/v0.4.6-preview)
- [Harbor 開發紀錄影片](https://youtu.be/37ImdbMhJ3E)
- [回報問題或建議](https://github.com/fanhow/harbor-preview/issues/new)

僅提供 Apple Silicon（M 系列）版；建置目標為 macOS 13 或更新版本，尚未實機驗證最低版本。不支援 Intel Mac 或 Windows。**目前未經 Apple 公證，macOS 可能會阻擋開啟。** 請勿關閉 Gatekeeper 或變更全系統安全設定。若系統擋下，不必強行安裝。

可以貼自己的 YouTube 網址或影片 ID 在所選資料夾比對檔名，但不會因此下載網路上的影片。請使用你自己製作或獲准使用的影片與字幕。若要回報，請勿附上帳號、私人字幕或影片檔。
